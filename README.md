# Мультимедийная галерея

Учебный проект — веб-сайт для просмотра изображений, видео и аудиоматериалов.

## Этап 1. Подготовка проекта

На первом этапе подготовлены:
- структура папок;
- главная страница, галерея и разделы изображений, видео и аудио;
- макеты регистрации, входа, личного кабинета, добавления материала и поиска;
- общий стиль, шапка сайта и мобильное меню;
- предварительная схема базы данных: пользователи, категории, материалы.

Пока это **интерфейс без подключения к серверу и базе данных**. Данные на карточках приведены для примера. Кнопки отправки форм отключены до реализации серверной части.

## Структура

- `src/index.html` — главная страница;
- `src/pages/` — остальные страницы;
- `src/assets/css/` — оформление сайта;
- `src/assets/js/` — мобильное меню;
- `src/assets/media/` — папка для изображений;
- `src/uploads/` — будущие загрузки пользователей;
- `backend/` — серверная часть (подготовлена папка);
- `database/schema.sql` — схема таблиц базы данных.

## Просмотр

Откройте `src/index.html` в браузере либо используйте расширение Live Server в VS Code. Для просмотра интерфейса PHP и MySQL пока не требуются.

## Следующий этап

Подключить PHP и MySQL, реализовать регистрацию, вход, личный кабинет и сохранение материалов.
